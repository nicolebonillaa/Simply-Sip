# Simply Sip

A mobile app for CSUN students to discover and filter drinks near campus based on dietary restrictions, allergies, calories, sugar content, and nutrition preferences.

## Tech Stack
- Frontend: React Native, React Navigation, react-native-maps
- Backend: Java (Spring Boot), MySQL
- API: REST with JWT authentication

## Getting Started
1. Clone the repo
2. Run `npm install`
3. iOS: `cd ios && pod install && cd ..`, then `npx react-native run-ios`
4. Android: `npx react-native run-android`
